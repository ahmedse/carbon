# Carbon Accounting Best Practices

## Overview

This guide provides practical recommendations for implementing and maintaining a robust carbon accounting system aligned with GHG Protocol requirements.

## Data Collection Best Practices

### 1. Establish Clear Boundaries

Before collecting data, establish:
- **Organizational boundaries** (equity share vs control approach)
- **Operational boundaries** (which Scope 1, 2, 3 categories to include)
- **Temporal boundaries** (fiscal year, calendar year)

### 2. Create a Data Collection Framework

**Primary Data Sources:**
- Utility bills (electricity, gas, water)
- Fuel purchase records
- Fleet management systems
- Expense reports (travel)
- Procurement systems (purchased goods)
- Waste management records

**Secondary Data Sources:**
- Industry benchmarks
- Emission factor databases
- Supplier declarations
- Life cycle assessment databases

### 3. Implement Robust Data Management

**Data Quality Requirements:**
- Completeness: Capture all relevant sources
- Consistency: Use same methodologies over time
- Accuracy: Verify data against source documents
- Transparency: Document all assumptions and methodologies

**Data Storage:**
- Centralized database or system
- Clear audit trail
- Version control for emission factors
- Backup and security protocols

## Emission Calculation Best Practices

### 1. Use Appropriate Emission Factors

**Factor Selection Hierarchy:**
1. Facility-specific factors (measured)
2. Country-specific factors
3. Regional factors
4. Default factors (IPCC, DEFRA)

**Factor Updates:**
- Review factors annually
- Document factor sources and vintages
- Recalculate base year if factors change significantly

### 2. Apply Consistent Methodologies

**Calculation Documentation:**
- Formula used
- Emission factor applied
- Data source
- Any assumptions made
- Uncertainty estimate

### 3. Handle Data Gaps Appropriately

**Gap-Filling Techniques:**
- Proxy data (similar facilities)
- Extrapolation (historical trends)
- Estimation methods (area-based, headcount-based)

**Documentation:**
- Clearly identify estimated vs actual data
- Quantify uncertainty
- Prioritize filling gaps for material sources

## Reporting Best Practices

### 1. Report Transparently

Include in reports:
- Scope and boundary explanation
- Methodology description
- Emission factors used and sources
- Data quality statement
- Exclusions with justification
- Restatements from prior years

### 2. Use Standard Metrics

**Absolute Metrics:**
- Total tonnes CO2e
- Emissions by scope
- Emissions by gas type

**Intensity Metrics:**
- Emissions per revenue
- Emissions per employee (FTE)
- Emissions per unit produced
- Emissions per square meter

### 3. Track Progress Effectively

**Year-over-Year Analysis:**
- Compare against base year
- Calculate reduction percentages
- Analyze drivers of change

**Target Tracking:**
- Progress toward science-based targets
- Actual vs target trajectory
- Intervention impact assessment

## Quality Assurance

### Internal Controls

**Data Validation:**
- Cross-check with source documents
- Reasonableness checks
- Comparisons to prior periods
- Unit conversion verification

**Review Process:**
- Multi-level approval
- Subject matter expert review
- Management sign-off

### External Assurance

**Verification Benefits:**
- Increased stakeholder confidence
- Identification of errors and improvements
- Regulatory compliance
- Enhanced credibility

**Assurance Levels:**
- Limited assurance (review-level)
- Reasonable assurance (audit-level)

## Common Pitfalls to Avoid

### Data Quality Issues
- Incomplete data collection
- Inconsistent boundary application
- Using outdated emission factors
- Double counting across scopes

### Calculation Errors
- Unit conversion mistakes
- Wrong emission factor application
- Missing GWP conversions
- Arithmetic errors

### Reporting Issues
- Inconsistent year-over-year methodology
- Inadequate documentation
- Missing exclusions disclosure
- Unclear base year adjustments

## Technology Recommendations

### Carbon Accounting Software

**Key Features to Look For:**
- Multi-source data integration
- Automated calculations
- Audit trail capability
- Reporting templates
- Factor library updates
- Verification support

### Integration Points
- ERP systems (financial data)
- Utility management systems
- Fleet management
- Travel booking platforms
- Procurement systems

## Continuous Improvement

### Annual Review Cycle
1. Assess data quality and completeness
2. Update emission factors
3. Review boundary changes
4. Evaluate new emission sources
5. Implement process improvements

### Maturity Progression
- Level 1: Basic inventory (Scope 1, 2)
- Level 2: Complete inventory (including Scope 3)
- Level 3: Verified inventory with targets
- Level 4: Integrated management with real-time tracking
- Level 5: Net-zero pathway implementation
