## 7. Notes / Debt

- `admin.py` does not register `CompensationComponent`, `CompensationPlan`, or `EmployeeCompensation` in Django Admin. This is not a functional failure but limits admin-level inspection. Recommend adding in a follow-up task.
- `EmployeeCompensationView.post()` uses `can_view_compensation` (checking `people:view_compensation`) rather than a separate `people:manage_compensation` capability. This means anyone who can VIEW compensation can also WRITE it. If a finer-grained permission split is desired, a `can_manage_compensation` helper should be added to `sensitivity.py`. Not a bug — matches the written contract — but worth noting.
