  - validationResults (object with valid/error arrays)
  - importing (boolean)
  - importOnlyValid (boolean)
  - error (string error message)

API Integration:
  - Endpoint: POST /carbon-api/datarows/bulk-import/
  - Content-Type: multipart/form-data
  - Form Fields:
    * file: CSV file
    * data_table: tableId
    * column_mapping: JSON string
    * mode: 'create'
  - Response: { created: number, failed: number, errors: array }

========================================
STEP DETAILS
========================================

STEP 1: FILE UPLOAD
- Drag-and-drop zone with visual feedback (dashed border)
- Accepts: .csv, .xlsx, .xls files
- Max size: 10MB
- Parsing: papaparse with header detection
- Output: csvHeaders array, parsedData array
- Next Button: Enabled after file selection

STEP 2: COLUMN MAPPING
- Table display: CSV headers → Table fields
- Auto-mapping logic:
  1. Exact match (case-insensitive)
  2. Fuzzy match (remove spaces/underscores)
  3. Falls back to unmapped if no match found
- Manual mapping: Dropdown for each column
- Summary: Shows mapped/unmapped counts
- Next Button: Enabled if at least 1 column mapped

STEP 3: VALIDATION PREVIEW
- Validation rules per field:
  * Required field check
  * Type validation (number, boolean, select)
  * Value range validation
  * Option set validation (select type)
- Output:
  * validCount: rows that passed validation
  * errorCount: rows with errors
  * errors: array of error details
  * validRows: validated data rows
- Error display:
  * Error summary by type (aggregated counts)
  * Error details table (first 10 rows)
  * Total error count shown
- Checkbox: "Import only valid rows"
- Import Button: Enabled if validCount > 0

FEATURES:
- Back/Next/Cancel navigation buttons
- Loading spinner during import
- Modal stays open on error (retry capable)
- Modal closes on successful import
- Error alerting with dismissible alert
- Form state preserved during navigation
- OnImportComplete callback with results
