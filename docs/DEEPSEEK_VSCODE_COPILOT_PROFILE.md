# DeepSeek VS Code Copilot Profile

This workspace now includes a recommended custom model profile for VS Code Copilot using your DeepSeek key.

## Recommended profile name

- `aastmt_deepseek-r1`

## Model identifier

- `deepseek/deepseek-r1`

## Purpose

Use this profile when you want a custom Copilot model optimized for complex reasoning and code generation inside the AAST Carbon workspace.

## Suggested configuration

If your VS Code Copilot or custom model integration supports named profiles, use the following values:

- Profile name: `aastmt_deepseek-r1`
- Model: `deepseek/deepseek-r1`
- API key: your DeepSeek API key

## Example usage

1. Open your VS Code Copilot settings or custom model profile settings.
2. Add a profile with the name `aastmt_deepseek-r1`.
3. Set the model identifier to `deepseek/deepseek-r1`.
4. Set the API key using your DeepSeek key.

## Notes

- Do not modify the platform superuser account (`ahmed`).
- This profile is intended for development and logic-heavy tasks in the Carbon workspace.
- Keep the profile name exact so VS Code Copilot can resolve it consistently.
